# হাজিরা হিসাব (Hazira Hisab)

দৈনিক মজুরি ও চুক্তিভিত্তিক শ্রমিকদের কাজের হাজিরা, আয়, প্রাপ্ত টাকা, বকেয়া এবং ব্যক্তিগত খরচের হিসাব রাখার আধুনিক ডিজিটাল খাতা অ্যান্ড্রয়েড অ্যাপ্লিকেশন।

---

## প্রধান বৈশিষ্ট্যসমূহ

- **হোম ড্যাশবোর্ড**: আজকের আয়-ব্যয়, মোট পাওনা বনাম অগ্রিম ব্যালেন্স এবং হাতে থাকা নগদ টাকার স্পষ্ট খতিয়ান।
- **হাজিরা হিসাব**: দিনভিত্তিক কাজের হাজিরা (হাফ দিন, পূর্ণ দিন, ওভারটাইম), নির্ধারিত হাজিরা রেট দিয়ে তাৎক্ষণিক হিসাব।
- **টাকা পাওয়ার খাতা**: মালিক/ঠিকাদারের কাছ থেকে প্রাপ্ত নগদ টাকার তালিকা।
- **ব্যক্তিগত খরচের হিসাব**: মেস খরচ, খাবার, যাতায়াত ও চিকিৎসা খরচের ট্র্যাকার।
- **স্মার্ট রিপোর্ট ও স্টেটমেন্ট**: দিন, সপ্তাহ, মাস ও সম্পূর্ণ সময়ের পূর্ণাঙ্গ আর্থিক প্রতিবেদন।
- **১০০% অফলাইন ও নিরাপদ**: সম্পূর্ণ ডাটা আপনার মোবাইলের লোকাল ডাটাবেজে (Room Database) সংরক্ষিত থাকে।
- **ব্যাকআপ ও রিস্টোর**: এক ক্লিকেই সম্পূর্ণ ডাটা JSON ফরম্যাটে এক্সপোর্ট ও শেয়ার করার সুবিধা।

## GitHub Actions দিয়ে APK তৈরি

আপনি খুব সহজেই GitHub Actions ব্যবহার করে কোনো লোকাল সফটওয়্যার বা জটিলতা ছাড়াই রেপোজিটরি থেকেই সরাসরি ইনস্টলেশনযোগ্য APK তৈরি করে নিতে পারেন।

### ধাপসমূহ:

1. **GitHub repository open করুন.**
2. উপরের মেনু থেকে **Actions tab খুলুন.**
3. বাম পাশের তালিকা থেকে **Build Android APK** (অথবা **Build APK**) workflow নির্বাচন করুন.
4. ডান পাশের **Run workflow** ড্রপডাউন বাটনে চাপুন (চাইলে debug বা release নির্বাচন করতে পারেন).
5. **Run workflow** সবুজ বাটনে ক্লিক করে Build শেষ হওয়া পর্যন্ত অপেক্ষা করুন (সাধারণত ২-৪ মিনিট সময় লাগে).
6. বিল্ড সম্পন্ন হলে **Successful workflow**-টির উপরে ক্লিক করে ওপেন করুন.
7. পেজের নিচের দিকে **Artifacts** সেকশনে যান এবং **hazira-hisab-apks** লিঙ্কে ক্লিক করে APK ডাউনলোড করুন.
8. ডাউনলোডকৃত ZIP ফাইলটি **extract করুন.**
9. আপনার ডিভাইসে **প্রয়োজনীয় APK install করুন.**

---

### APK ও আর্কিটেকচার (ABI) নির্দেশিকা:

- **Universal APK (`app-universal.apk` / `app-debug.apk`)**: এই অ্যাপ্লিকেশনটি ১০০% পিওর Kotlin ও Jetpack Compose দিয়ে তৈরি এবং এতে কোনো এক্সটার্নাল C/C++ নেটিভ লাইব্রেরি নেই। তাই Universal APK-টি যেকোনো অ্যান্ড্রয়েড ডিভাইসে (ARM বা x86) সমান দক্ষতায় ইন্সটল ও ব্যবহার করা যায়।
- **arm64-v8a**: বর্তমানে ব্যবহৃত প্রায় সকল আধুনিক ৬৪-বিট ARM অ্যান্ড্রয়েড ফোনের জন্য প্রযোজ্য।
- **armeabi-v7a**: তুলনামূলক পুরোনো ৩২-বিট ARM অ্যান্ড্রয়েড ডিভাইসের জন্য।
- **x86 / x86_64**: প্রধানত অ্যান্ড্রয়েড স্টুডিও এমুলেটর অথবা Intel প্রসেসরযুক্ত অ্যান্ড্রয়েড সিস্টেমের জন্য।
