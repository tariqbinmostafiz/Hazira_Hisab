# হাজিরা হিসাব | Hazira Hisab

দৈনিক হাজিরা, আয়, পাওনা টাকা এবং খরচের হিসাব সহজে সংরক্ষণ ও পরিচালনার জন্য একটি Android অ্যাপ।

## ✨ প্রধান ফিচার

- **হোম ড্যাশবোর্ড:** বর্তমান মাসের হিসাব ও পাওনা টাকার সারসংক্ষেপ।
- **হাজিরা হিসাব:** পূর্ণ হাজিরা ও অর্ধেক হাজিরার হিসাব রাখা।
- **পাওনা ও পেমেন্ট:** প্রাপ্য টাকা এবং আদায় করা টাকার হিসাব সংরক্ষণ।
- **খরচ ব্যবস্থাপনা:** খাবারসহ দৈনন্দিন খরচ নথিভুক্ত করা।
- **মাসভিত্তিক হিসাব:** প্রতিটি মাসের হিসাব আলাদাভাবে দেখা।
- **বিস্তারিত রিপোর্ট:** আয়, পাওনা ও খরচের হিসাব পর্যালোচনা।
- **ব্যাকআপ ও পুনরুদ্ধার:** JSON ব্যাকআপ সংরক্ষণ ও প্রয়োজন হলে পুনরায় ইমপোর্ট করার সুবিধা—প্রকল্পের বর্তমান সংস্করণে সমর্থিত ফিচার অনুযায়ী।

## 📱 নেভিগেশন

অ্যাপের মূল নেভিগেশন চারটি বিভাগে সাজানো:

- হোম
- হাজিরা
- পাওনা
- খরচ

রিপোর্ট ও সেটিংস উপরের ডান পাশ থেকে খোলা যায়—যদি আপনার ইনস্টল করা সংস্করণে এই UI আপডেট অন্তর্ভুক্ত থাকে।

## 🎯 কাদের জন্য

দৈনিক মজুরিভিত্তিক কাজ করেন এবং হাজিরা, আয়, পাওনা ও খরচের হিসাব সহজভাবে রাখতে চান—এমন ব্যবহারকারীদের কথা মাথায় রেখে অ্যাপটি তৈরি।

## 🛠️ প্রযুক্তি

এটি একটি Android অ্যাপ। ব্যবহৃত framework, language ও build requirements প্রকল্পের source code এবং Gradle configuration অনুযায়ী দেখুন।

## 🚀 ইনস্টলেশন

1. GitHub Releases থেকে আপনার ডিভাইসের জন্য প্রকাশিত APK ডাউনলোড করুন।
2. Android-এ APK ইনস্টল করার অনুমতি প্রয়োজন হলে সেটি দিন।
3. অ্যাপ খুলে হাজিরা ও লেনদেনের তথ্য যোগ করুন।

> নিরাপত্তার জন্য APK কেবল বিশ্বস্ত রিলিজ সোর্স থেকে ডাউনলোড করুন। নতুন সংস্করণ ইনস্টল করার আগে গুরুত্বপূর্ণ হিসাবের ব্যাকআপ রেখে দিন।

## 💾 ব্যাকআপ
